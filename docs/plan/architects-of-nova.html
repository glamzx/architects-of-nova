Решение, которое нужно принять первым

Дух Star Wars, но без имён и символов Star Wars

При сдаче проекта команда ставит галочку: «мы не использовали защищённые авторским правом материалы без разрешения». Джедаи, ситхи, световые мечи, Сила, «Звезда смерти», бегущий титр-crawl, музыка и персонажи принадлежат Lucasfilm/Disney. С ними проект рискует снятием с глобального судейства, а в Roblox — удалением через Rights Manager. Логотип NASA («meatball») тоже нельзя ставить без разрешения.

Берём настроение
  • Галактика далеко-далеко, Академия против Гегемонии
  • Голограммы-брифинги, дроид-напарник, ангар с кораблём
  • Прыжок через гиперпространство как переход между уровнями
  • Мастер-наставник, бывший лучший ученик стал антагонистом
  • Свой «кодекс»: «Сила — в запасе» (инженерный запас = главная добродетель)
Не берём
  • Названия, имена, планеты, корабли, расы из Star Wars
  • Световые мечи и «Силу» как механику
  • Логотип, шрифт, жёлтый титр-crawl, музыку Джона Уильямса
  • Модели из Creator Store, которые копируют X-wing, TIE и т.п.
  • Слово «Star Wars» в названии игры и описании

Для судей это ещё и плюс к Creativity: оригинальная вселенная, где «магия» заменена инженерией.

Сюжет

Тишина над сектором Нова

Далёкое будущее. Колонии сектора Нова одна за другой замолкают: звезда Нова-Прайм стала нестабильной, а Гегемония адмирала Векса предлагает «быстрые» корабли, которые ломаются. Последняя надежда — Академия Архитекторов и её Архив Первопроходцев: древние записи о миссиях Земли. Это и есть реальные данные NASA. Каждая открытая запись даёт кадетам новую технологию.

Акт I · Пробуждение · ~20 мин

Кадеты

Команда прибывает в Цитадель. Пролог: собрать крошечный кубсат «Искра» и вернуть связь со станцией. Миссия «Маяк» восстанавливает связь с колониями. Первая встреча с Вексом: он смеётся над «лишним запасом».

Акт II · Тень · ~30 мин

Тайна

Ледяной зонд на луне, посадка на красную планету, телескоп в глубоком космосе. Телескоп видит правду: Гегемония сдвинула астероид, чтобы «спасти» колонию за деньги. Наставница Кейд раскрывает прошлое Векса: его миссия погибла, потому что он срезал запас.

Акт III · Молот · ~20 мин

Финал

Зонд к ледяной луне Эвридике находит источник «Тишины». Финал: отклонить астероид под солнечной бурей, всей командой на всех станциях. Векс предлагает «дешёвую» деталь со скрытым риском. Выбор игроков меняет концовку.

Наставник

Мастер Орина Кейд

Ветеран-руководитель полётов. Говорит голограммой, одной фразой. Даёт миссии.

Напарник

Дроид БИП-7

Летающий шар. Подсказывает без слов: светится, пищит, рисует стрелки. В соло берёт пустые роли. Кастомизируется.

Антагонист

Адмирал Сайрус Векс

Бывший лучший кадет. Философия: «запас для трусов». Зеркало ошибок игрока. В концовке можно его переубедить.

Торговец и Архив

Грок и ИИ «ЭХО»

Грок продаёт модули и косметику за кредиты миссий. ЭХО хранит голо-экспонаты реальных миссий NASA.

Карта кампании · ~70 минут

Семь миссий, каждая учит одному компромиссу

Все миссии работают на одних и тех же четырёх системах (ангар, старт, центр управления, разбор). Новая миссия — это новая таблица данных, а не новый код. Так час контента реально собрать за хакатон.

Игровой цикл

Брифинг → Сборка → Старт → Операции → Разбор

Масштаб

1, 2, 3 или 4 игрока

Соло: дроид БИП-7 держит пустые станции на «авто» с упрощённой логикой. Вдвоём: каждый берёт по две роли. Сложность событий растёт с числом игроков.

Переговоры

Общий кошелёк

Бюджет один на всех. Учёный хочет второй прибор, Инженер — запасную батарею. Командир запускает голосование: 4 голограммы над столом, 10 секунд.

Синхронность

Действия «в одну секунду»

Раскрытие зеркала, стыковка, манёвр уклонения: несколько игроков нажимают свои рычаги одновременно. Удачная синхронизация даёт очки «Команда».

Правила интерфейса

Шесть иконок вместо слов

kgМасса ⚡Питание ₵Бюджет ▣Данные ⌁Связь ⏳Время

Цвет состояния везде один: зелёный — норма, жёлтый — запас меньше 10%, красный — превышение (пульсирует).

Жёсткие лимиты на текст

  • Не больше 7 слов на одной плашке
  • Брифинг: голограмма + 1 фраза + картинка цели, до 10 секунд
  • Обучение действием: БИП-7 подлетает и подсвечивает, что нажать
  • Факт NASA: 1 строка + 3D-модель в Архиве, по желанию
  • Последствия показываются стрелками и анимацией, а не текстом
  • Субтитры и короткие голосовые реплики (озвучка — P2)

Упрощённая, но честная физика

Солнечная энергия
Мощность панели ∝ 1/r². У Марса ~43% от земной, у Юпитера ~4%
Проверка ракеты
Масса корабля ≤ грузоподъёмность ракеты для выбранной орбиты (для GEO и дальнего космоса меньше, чем для LEO)
Связь
Скорость данных падает с расстоянием, задержка = расстояние / скорость света
Тень
На низкой орбите часть каждого витка в тени: работают только батареи
Запас
Меньше 10% запаса по массе или мощности → у события есть шанс «сломать» систему

Включить Studio MCP (1 минута)

Roblox Studio → панель Assistant → … → Manage MCP Servers → включить Enable Studio as MCP server → в Quick connect включить Claude Code. Затем перезапустить сессию Claude. Если Quick connect не находит, команда для Windows: cmd.exe /c %LOCALAPPDATA%\Roblox\mcp.bat

Также в Game Settings → Security включить Allow HTTP Requests, чтобы игра получала живые данные NASA DONKI и NeoWs.
