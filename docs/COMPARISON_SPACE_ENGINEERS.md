# Architects of Nova vs Space Engineers (and Kerbal Space Program)

There is no Roblox game called "Space Engineering" (Roblox search for "space engineering", "space engineer" and
"space engineers" returns no such title). The closest match is **Space Engineers** (Keen Software House, PC/console,
Steam: 89 % positive of ~68 k reviews). The closest *learning* space game is **Kerbal Space Program** (Steam: 96 % of
~85 k reviews, Common Sense Media 8+). Below: their main weaknesses and how Architects of Nova answers each one.

| Their weakness (from reviews) | Space Engineers | Kerbal SP | Architects of Nova answer |
|---|---|---|---|
| Hard first hour, poor tutorial, players rely on YouTube/wikis | yes | yes | Cold-open story, 3 guided acts with a screen arrow from your character, BIP-7 radio tips, NASA file (key N) |
| Not made for kids: 12+ / 8+ with parent; failures "break apart" | yes | explosions | Roblox-style art for ages 6–12; no "mission lost" — a NO-GO poll explains the fix **before** launch, failures add improvement tasks |
| No clear goals in sandbox | yes | career only | 7 story chapters, 2 landing sites per world, daily quests, stars, ranks |
| Grindy, repetitive | survival grind | science grind | Each chapter adds a new idea (eclipse, polar orbit, landing order, folding mirror, radiation, impact) and new mini-games |
| Complex controls, cluttered UI | yes | yes | One key (E) + short repair mini-games with big buttons; contextual inspect card instead of floating labels |
| Needs a strong PC, crashes, save corruption | yes | big rockets lag | Runs in Roblox on PC, tablet, phone; profile saved on the server (DataStore) |
| Multiplayer lag / no co-op | server lag | single-player only | Co-op for 1–4 with roles (Commander, Engineer, Scientist, Comms), heavy parts carried together, sync tasks, team votes; pings (V) work without text chat |
| Paid DLCs | 20 DLCs | — | Free; credits are earned by playing only (no paid boosts, no loot boxes) |
| Science accuracy unclear | speed cap ~100 m/s | very accurate but hard | Simplified but honest NASA-based rules (margin, eclipse batteries, 1/r² power, light delay, launcher capacity per orbit) with real NASA sources (docs/NASA_SOURCES.md) |

## Roblox engagement features added (ages 6–12, child-safe)

- Daily reward (streak grows up to day 5; missing a day takes nothing away).
- Daily quests: 3 per day from 6 types (fix emergencies, win repair mini-games, launch, finish landing sites, carry a heavy part together, complete a mission).
- Credits now matter: repair kits (instant fix, key R), mission grants (+15 budget), BIP-7 Turbo (fixes one missed emergency per mission), plus suits/visors/BIP skins.
- Promo codes in Settings (free credits/items, never sold).
- Pings (V) so kids with chat off can still play together.
- Visual team votes: every choice card shows a live 3D preview (dark icy crater vs sunlit rim, one big satellite vs a swarm,
  delta vs plain, direct route vs gravity assist...), green/amber pros and cons and one line about the consequence.
- A personal "Your job" card for each role in every mission (Commander, Engineer, Scientist, Comms), so all four players matter.
- Drivable 4-seat rovers (Rover Bay at the Citadel, one rover at each ground site) and a "drive the rover to the beacon" task on the Moon and Mars.
- Full spacesuits whenever the crew flies or walks in space; cutscenes show the whole crew seated in a 4-seat capsule, the lander touching down,
  hopping between sites and lifting off for home.
- Not added on purpose: trading, loot boxes, paid boosts, rewarded ads (not allowed/appropriate for under-13).
